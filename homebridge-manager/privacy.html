SOUKROMÍ

Vaše Homebridge data zůstávají mezi vámi a vaším serverem.

Poslední aktualizace: 26. září 2026 · HB Control 0.6.4 build 16

Produktový web

Tento produktový web je informační stránka. Nepřipojuje se k vašemu Homebridge, nečte konfiguraci serveru a nevyžaduje přihlašovací údaje Homebridge.

HB Control

Aplikace se připojuje pouze k Homebridge serveru zvolenému uživatelem. Ve výchozím stavu heslo neukládá. Pokud uživatel výslovně zapne bezpečné přihlášení, adresa serveru, uživatelské jméno a heslo se uloží pouze do iOS Keychainu na daném zařízení a jejich načtení vyžaduje Face ID, Touch ID nebo kód zařízení. Přístupový token zůstává pouze v aktuální relaci.

Demo Mode

Demo Mode používá pouze lokální ukázková data a nepřipojuje se ke skutečnému Homebridge serveru ani na něm neprovádí změny.

Diagnostika

Diagnostika zůstává v zařízení, dokud ji uživatel sám nezkopíruje nebo nesdílí. Při kopírování aplikace maskuje běžné adresy serveru, IP adresy, MAC adresy a Bearer tokeny.

Analytika a sledování

HB Control nepoužívá reklamní tracking, nevytváří reklamní profil uživatele a nemá vlastní analytický nebo telemetrický backend. Produktový web neobsahuje vlastní reklamní ani analytické skripty.

Uchování a smazání

HB Control nemá vlastní uživatelský účet ani vývojářský backend pro ukládání Homebridge přihlašovacích údajů nebo diagnostiky. Uložené přihlášení lze kdykoliv smazat v aplikaci. Odhlášení odstraní token aktuální relace a jednorázové 2FA kódy se neukládají.

Pluginy a služby třetích stran

Homebridge pluginy jsou samostatný software nainstalovaný na vašem serveru a mohou používat vlastní síťové služby a zásady ochrany soukromí.

Lokální síť a VPN

HB Control je navržen pro důvěryhodnou lokální síť nebo vlastní zabezpečené vzdálené připojení, například VPN. Administrační port Homebridge není potřeba veřejně vystavovat do internetu.
