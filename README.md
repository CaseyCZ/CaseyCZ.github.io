## O webu

Web slouží jako centrální místo pro aktuální projekty CaseyCZ. Každý projekt má vlastní stránku nebo repozitář a z hlavního webu se k němu dá rychle dostat.

## Projekty

- 🏠 **Homebridge Manager** — mobilní správa Homebridge pro iPhone / PWA
- 🎮 **GameS Calendar** — herní kalendář a vyhledávač vydání
- 📱 **Scriptable Apps** — widgety a nástroje pro iPhone
- ✈️ **Travel Checklist** — pomocník na cesty
- ▶️ **Stremio Sosáč** — katalogy, metadata a video streamy
- 💬 **Sosáč Subtitles** — samostatný Stremio addon pro titulky
