GOOD TO KNOW

Questions?
Here are the answers.

An official contact and support channel will be published before release.

Is this an official Homebridge app?

No. Homebridge Manager is an independent CaseyCZ project. It uses interfaces provided by an existing Homebridge UI installation and is not a product of the Homebridge team or Apple.

Do I need to edit JSON?

Not for normal configuration of supported plugins. The app can generate forms from plugin schemas. An advanced JSON editor remains available for more complex cases.

Does it work away from home?

Yes, if you have a secure path to your Homebridge, for example through your own VPN such as Tailscale. Homebridge does not need to be exposed directly to the public internet.

Can I download it from the App Store now?

Not yet. The project is in development. PWA is the first planned release form, followed by native iOS distribution after validation and completion.

What works without a connection?

The product website and some static interface elements. Administration, logs, updates and server status require a reachable Homebridge server.

Are multiple servers or HOOBS supported?

The current development branch targets one Homebridge server using Config UI X. Multiple profiles and other platforms are not currently promised as supported features.

Is the development build suitable for production use?

Test carefully. Create a backup before configuration changes or restore operations, and only run administrative actions when you understand their impact.
