DOBRÉ VĚDĚT

Otázky?
Tady jsou odpovědi.

Oficiální kontakt a kanál podpory zveřejníme před vydáním.

Je to oficiální aplikace Homebridge?

Ne. HB Control je nezávislý projekt vývojáře CaseyCZ. Využívá rozhraní existujícího Homebridge UI a není produktem týmu Homebridge ani společnosti Apple.

Musím umět upravovat JSON?

Ne pro běžné nastavení podporovaných pluginů. Aplikace umí sestavit formuláře podle schématu pluginu. JSON editor zůstává dostupný pro pokročilé případy.

Funguje aplikace i mimo domov?

Ano, pokud máte bezpečnou cestu ke svému Homebridge, například přes vlastní VPN jako Tailscale. Homebridge není nutné vystavovat veřejně do internetu.

Mohu ji už stáhnout z App Storu?

Zatím ne. Projekt je ve vývoji. Build 16 je App Store kandidát. Veřejné vydání přijde až po Xcode/TestFlight a fyzickém ověření.

Co funguje bez připojení?

Produktový web a některé statické části rozhraní. Správa, logy, aktualizace a stav serveru samozřejmě vyžadují dosažitelný Homebridge.

Funguje Demo Mode bez Homebridge serveru?

Ano. Demo Mode používá pouze lokální ukázková data, takže lze projít Dashboard, pluginy, aktualizace, Server Settings, zálohy i logy bez připojení ke skutečnému serveru.

Je vývojová verze vhodná pro ostrý provoz?

Testujte opatrně. Před změnami konfigurace nebo restore operacemi vytvořte zálohu a administrátorské akce spouštějte jen tehdy, když rozumíte jejich dopadu.
