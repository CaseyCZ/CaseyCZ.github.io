PRIVACY

Your Homebridge data stays between you and your server.

Last updated: September 26, 2026 · HB Control 0.6.4 build 16

Product website

This product website is informational. It does not connect to your Homebridge, read your server configuration or request Homebridge credentials.

HB Control

The app connects only to the Homebridge server selected by the user. By default, the password is not stored. If secure sign-in is explicitly enabled, the server address, username and password are stored only in iOS Keychain on that device and require Face ID, Touch ID or the device passcode before being loaded. The access token remains limited to the current session.

Demo Mode

Demo Mode uses local sample data only and does not connect to or modify a real Homebridge server.

Diagnostics

Diagnostics remain on the device unless the user explicitly copies or shares them. Copied diagnostics redact common server URLs, IP addresses, MAC addresses and Bearer tokens.

Analytics and tracking

HB Control does not use advertising tracking, build an advertising profile or operate its own analytics or telemetry backend. The product website contains no first-party advertising or analytics scripts.

Retention and deletion

HB Control has no developer-operated user account or backend that stores Homebridge credentials or diagnostics. Saved sign-in data can be deleted at any time in the app. Signing out clears the current session token and one-time 2FA codes are never stored.

Plugins and third-party services

Homebridge plugins are separate software installed on your server and may use their own network services and privacy policies.

Local network and VPN

HB Control is designed for a trusted local network or your own secure remote connection such as a VPN. There is no need to expose the Homebridge administration port directly to the public internet.
